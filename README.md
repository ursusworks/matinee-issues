# Matinee issues

Bug reports and feature requests for [Matinee](https://ursusworks.github.io/matinee/), the Emby app for Xbox Series X|S.

[Report a problem or suggest something](https://github.com/ursusworks/matinee-issues/issues/new/choose)

Matinee is closed source, so this repo holds no code. Issues here are public: please don't post server addresses, API keys, passwords or anything else private.
